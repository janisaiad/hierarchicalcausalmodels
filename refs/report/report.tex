\begin{abstract}
\setlength{\parindent}{0pt}
Nous présentons une implémentation de bout en bout des Modèles Causaux Hiérarchiques (HCM) pour l'inférence causale sur données imbriquées, en prolongeant les SCM/CGM classiques vers des structures unit--sub unit. Notre contribution combine : (i)~la redérivation du cadre théorique (transformations \textit{collapse/augment/marginalize}, critères d'identification, do-calculus), (ii)~un backend formel--numérique unifié où l'identification pyAgrum produit à la fois une formule LaTeX et une AST exécutable, ensuite compilée en estimateur via \texttt{ast\_to\_estimator}, et (iii)~une validation expérimentale extensive sur motifs canoniques, suites synthétiques avec vérités terrain, et étude appliquée STAR. Les résultats confirment la validité du pipeline d'identification/estimation, mettent en évidence les régimes de stabilité/instabilité selon la structure de graphe, et documentent l'impact de facteurs manquants sur la fonctionnelle effectivement estimée. Nous montrons en outre que la parallélisation des évaluations d'ATE est un levier pratique majeur pour la scalabilité de la bibliothèque. Le package \texttt{hierarchicalcausalmodels} fournit ainsi une base reproductible, formellement fondée et opérationnelle pour l'inférence causale hiérarchique.
\end{abstract}

\subsection{Motivation et contexte}

Un défi fondamental en inférence causale est que de nombreux jeux de données sont hiérarchiques : les observations ne sont pas des unités indépendantes mais des sous-unités imbriquées dans des unités plus grandes.
Considérons des élèves au sein d'écoles, des cellules au sein de patients, ou des citoyens au sein d'États.
Dans de tels contextes, les variables au niveau de l'unité (par ex., le budget d'une école) peuvent affecter les variables au niveau des sous-unités (par ex., les notes d'élèves individuels), et vice versa.
Les outils classiques d'inférence causale---Modèles Causaux Structurels (SCM), do-calculus, ajustement par porte arrière/avant---sont construits pour des données plates, non hiérarchiques.
Lorsque les données sont hiérarchiques, agréger simplement les données de sous-unités en résumés au niveau de l'unité (par ex., moyennes de classe) jette des informations cruciales pour l'identification.

Ce PSC est centré sur l'article \emph{Hierarchical Causal Models} d'Eli N. Weinstein et David M. Blei (2023), qui propose un cadre systématique pour l'inférence causale avec des données imbriquées.
L'idée clé est que la structure des données hiérarchiques peut souvent \emph{permettre} l'identification causale dans des situations où elle serait impossible avec des données non hiérarchiques.

À notre connaissance, peu de travaux offrent un pipeline unifié pour données hiérarchiques réelles combinant découverte causale, identification HCM par do-calculus et estimation plug-in de bout en bout (de la donnée brute à l'ATE), les outils récents comme \texttt{y0} restant principalement symboliques et ne couvrant pas cette chaîne d'estimation numérique complète.

\subsection{Objectifs du PSC}

Notre PSC avait trois objectifs principaux :
\begin{enumerate}
  \item \textbf{Compréhension théorique :} Lire, comprendre et redériver le cadre mathématique des HCM, incluant les définitions de graphes, les transformations collapse/augment/marginalize, l'extension du do-calculus aux HCM, et la théorie de l'estimation.
  \item \textbf{Implémentation :} Construire un package Python modulaire et complet implémentant le pipeline HCM---de la spécification du modèle à l'identification puis à l'estimation---en suivant la théorie de l'article.
  \item \textbf{Validation :} Valider l'implémentation en récupérant des Effets Moyens du Traitement (ATE) connus sur des jeux de données synthétiques générés à partir de HCM paramétriques pour les trois motifs principaux.
\end{enumerate}

\section{Rappels : Inférence Causale Classique}
\label{sec:background}

\subsection{Modèles Causaux Structurels (SCM)}

\begin{definition}[Modèle Causal Structurel (SCM)]
Un Modèle Causal Structurel (SCM) est un tuple $\Mc = (\mathbf{V}, \mathbf{U}, \mathcal{F}, \pr(\mathbf{U}))$ où :
\begin{itemize}
  \item $\mathbf{V} = \{V_1, \ldots, V_k\}$ est l'ensemble des variables observées endogènes.
  \item $\mathbf{U} = \{U_1, \ldots, U_k\}$ est l'ensemble des variables exogènes (bruits).
  \item $\mathcal{F} = \{f_1, \ldots, f_k\}$ est l'ensemble des équations structurelles : $V_i = f_i(\pa(V_i), U_i)$, où $\pa(V_i)$ désigne les parents de $V_i$ dans le graphe acyclique dirigé (DAG) $\mathcal{G}$.
  \item $\pr(\mathbf{U}) = \prod_i \pr(U_i)$ est une distribution produit sur des variables de bruit indépendantes.
\end{itemize}
\end{definition}

Un SCM induit une distribution jointe sur $\mathbf{V}$ et, via l'opérateur \emph{do}, une famille de distributions interventionnelles.
L'intervention $\rmdo(V_i = v)$ dans un SCM consiste à remplacer l'équation structurelle de $V_i$ par la constante $V_i = v$, coupant ainsi toutes les influences entrantes.

\subsection{Modèles Graphiques Causaux (CGM)}

\begin{definition}[Modèle Graphique Causal (CGM)]
Un Modèle Graphique Causal (CGM) est une paire $(\mathcal{G}, \pr)$ où $\mathcal{G}$ est un DAG et $\pr$ est une distribution jointe markovienne par rapport à $\mathcal{G}$.
Chaque variable se factorise comme $\pr(\mathbf{V}) = \prod_i \pr(V_i \g \pa(V_i))$.
\end{definition}

Les CGM supportent le \emph{do-calculus} pour le raisonnement interventionnel : l'intervention $\rmdo(V_i = v)$ coupe tous les arcs entrants vers $V_i$ et fixe sa valeur à $v$.
On note $\mathcal{G}_{\overline{X}}$ le graphe obtenu en supprimant tous les arcs entrant dans $X$, et $\mathcal{G}_{\underline{X}}$ celui obtenu en supprimant tous les arcs sortant de $X$.

\subsection{Do-Calcul et ses Axiomes}
\label{sec:do_calculus}

\begin{definition}[Identifiabilité]
L'\emph{identification} est le problème d'exprimer une quantité interventionnelle $\pr(Y \g \rmdo(A = a))$ uniquement en termes de la distribution observationnelle $\pr(\mathbf{V})$.
Une quantité causale est dite \emph{identifiable} si elle peut être calculée de manière unique à partir de la distribution observationnelle, pour tout SCM compatible avec le graphe.
\end{definition}

Le do-calculus de Pearl \citep{Pearl2009} fournit un système complet de règles pour manipuler des expressions interventionnelles.
Il est fondé sur la notion de \emph{d-séparation} dans des graphes modifiés.

\begin{theorem}[Do-Calcul de Pearl --- Trois Règles]
Soit $\Mc$ un SCM avec graphe $\mathcal{G}$, et soient $X, Y, Z, W$ des ensembles disjoints de variables.
Les trois règles suivantes sont valides :

\medskip
\noindent\textbf{Règle 1 --- Insertion/Suppression d'observations :}
\begin{equation}
  \pr(Y \g \rmdo(X), Z, W) = \pr(Y \g \rmdo(X), W)
  \quad \text{si } (Y \perp\!\!\!\perp Z \g X, W)_{\mathcal{G}_{\overline{X}}}.
  \label{eq:rule1}
\end{equation}
\emph{Interprétation :} On peut ignorer $Z$ dans le conditionnement si $Y$ et $Z$ sont d-séparés dans le graphe où les arcs entrant dans $X$ sont supprimés.
Cette règle permet d'insérer ou de supprimer des observations non pertinentes.

\medskip
\noindent\textbf{Règle 2 --- Échange action/observation :}
\begin{equation}
  \pr(Y \g \rmdo(X), \rmdo(Z), W) = \pr(Y \g \rmdo(X), Z, W)
  \quad \text{si } (Y \perp\!\!\!\perp Z \g X, W)_{\mathcal{G}_{\overline{X},\underline{Z}}}.
  \label{eq:rule2}
\end{equation}
\emph{Interprétation :} Une intervention sur $Z$ peut être remplacée par une simple observation de $Z$ lorsque $Y$ et $Z$ sont d-séparés dans le graphe où les arcs entrant dans $X$ et les arcs sortant de $Z$ sont supprimés.
Cette règle formalise le passage de l'interventionnel à l'observationnel.

\medskip
\noindent\textbf{Règle 3 --- Suppression d'actions :}
\begin{equation}
  \pr(Y \g \rmdo(X), \rmdo(Z), W) = \pr(Y \g \rmdo(X), W)
  \quad \text{si } (Y \perp\!\!\!\perp Z \g X, W)_{\mathcal{G}_{\overline{X}, \overline{Z(W)}}},
  \label{eq:rule3}
\end{equation}
où $Z(W)$ désigne les nœuds de $Z$ qui ne sont pas ancêtres de $W$ dans $\mathcal{G}_{\overline{X}}$.
\emph{Interprétation :} Une intervention sur $Z$ est sans effet sur $Y$ si $Z$ n'a aucun chemin actif vers $Y$ dans le graphe approprié.

\end{theorem}

\subsection{Critère de porte arrière (Backdoor)}

\begin{definition}[Chemin de porte arrière]
Un \emph{chemin de porte arrière} de $A$ vers $Y$ dans $\mathcal{G}$ est un chemin qui commence par un arc entrant dans $A$ (c'est-à-dire qui « remonte » vers un ancêtre de $A$).
Ces chemins transmettent une association confondante entre $A$ et $Y$ sans passer par des effets causaux directs.
\end{definition}

\begin{definition}[Critère de porte arrière]
Un ensemble de variables observées $\mathbf{Z}$ satisfait le \emph{critère de porte arrière} par rapport à $(A, Y)$ dans $\mathcal{G}$ si :
\begin{enumerate}[label=(\roman*)]
  \item $\mathbf{Z}$ ne contient aucun descendant de $A$,
  \item $\mathbf{Z}$ bloque tous les chemins de porte arrière de $A$ vers $Y$.
\end{enumerate}
\end{definition}

\paragraph{Formule d'ajustement par porte arrière.}
Si $\mathbf{Z}$ satisfait le critère de porte arrière par rapport à $(A, Y)$, alors l'effet causal est identifiable :
\begin{equation}
  \pr(Y = y \g \rmdo(A=a)) = \sum_{\mathbf{z}} \pr(Y=y \g A=a, \mathbf{Z}=\mathbf{z})\, \pr(\mathbf{Z}=\mathbf{z}).
  \label{eq:backdoor}
\end{equation}

\paragraph{Intuition.}
Le critère de porte arrière formalise l'idée de « contrôler pour les confondants ».
En conditionnant sur $\mathbf{Z}$, on bloque toute association non causale entre $A$ et $Y$, de sorte que la distribution conditionnelle $\pr(Y \g A=a, \mathbf{Z}=\mathbf{z})$ reflète uniquement l'effet causal direct de $A$ sur $Y$.
La marginalisation sur $\pr(\mathbf{Z})$ recouvre ensuite la distribution interventionnelle non conditionnée.

\paragraph{Exemple.}
Dans le motif \textsc{Confondant} avec $U$ observé, $\mathbf{Z} = \{U\}$ satisfait le critère de porte arrière :
\begin{equation}
  \pr(Y \g \rmdo(A=a)) = \sum_{u} \pr(Y \g A=a, U=u)\, \pr(U=u).
\end{equation}
Si $U$ est \emph{non observé}, le critère n'est plus satisfait par aucun ensemble $\mathbf{Z} \subseteq \mathbf{V}_\text{obs}$ et il faut recourir à d'autres méthodes (porte avant, variables instrumentales).

\paragraph{Cas particulier : régression linéaire.}
Lorsque les équations structurelles sont linéaires et $\mathbf{Z}$ inclut tous les confondants, Éq.~\eqref{eq:backdoor} se réduit à l'estimateur MCO standard.
La formule de porte arrière est donc une généralisation non-paramétrique de la régression ajustée sur les covariables.

\subsection{Critère de porte avant (Front-door)}

\begin{definition}[Critère de porte avant]
Un ensemble de variables observées $\mathbf{M}$ satisfait le \emph{critère de porte avant} par rapport à $(A, Y)$ dans $\mathcal{G}$ si :
\begin{enumerate}[label=(\roman*)]
  \item Tous les chemins dirigés de $A$ vers $Y$ passent par $\mathbf{M}$ (i.e., $\mathbf{M}$ intercepte tous les effets causaux de $A$ sur $Y$),
  \item Il n'existe pas de chemin de porte arrière non bloqué de $A$ vers $\mathbf{M}$,
  \item Tous les chemins de porte arrière de $\mathbf{M}$ vers $Y$ sont bloqués par $A$.
\end{enumerate}
\end{definition}

\paragraph{Formule d'ajustement par porte avant.}
Si $\mathbf{M}$ satisfait le critère de porte avant par rapport à $(A, Y)$, et si $\pr(A=a) > 0$, alors :
\begin{equation}
  \pr(Y \g \rmdo(A=a)) = \sum_{m} \pr(M=m \g A=a) \sum_{a'} \pr(Y \g A=a', M=m)\, \pr(A=a').
  \label{eq:frontdoor}
\end{equation}

\paragraph{Intuition.}
La porte avant s'applique quand les confondants entre $A$ et $Y$ sont non observés, mais qu'un médiateur $M$ (qui intercepte le chemin causal $A \to Y$) est observable.
La stratégie est en deux étapes :
\begin{enumerate}
  \item Identifier l'effet de $A$ sur $M$ : comme il n'y a pas de porte arrière ouverte entre $A$ et $M$ (condition (ii)), cet effet est directement identifiable : $\pr(M \g \rmdo(A=a)) = \pr(M \g A=a)$.
  \item Identifier l'effet de $M$ sur $Y$ : en conditionnant sur $A$ comme instrument (condition (iii)), on bloque le chemin confondant entre $M$ et $Y$.
\end{enumerate}
La composition de ces deux étapes donne Éq.~\eqref{eq:frontdoor}.

\paragraph{Exemple : motif fumeur-cancer.}
$A$ = tabagisme, $M$ = goudron dans les poumons (observable), $Y$ = cancer, $U$ = prédisposition génétique (non observable).
On a $U \to A$, $U \to Y$, $A \to M \to Y$.
Ici $M$ satisfait le critère de porte avant et permet d'identifier l'effet du tabagisme sur le cancer malgré la prédisposition génétique non observée.

\paragraph{Lien avec le motif \textsc{Confondant \& Interférence} (HCM).}
Dans le modèle collapsé, $Z_i$ (agrégat des traitements sub unit) joue le rôle du médiateur $M$ : $Q^a_i \to Z_i \to Q^{y|a}_i$, avec $U_i$ confondant $Q^a_i$ et $Q^{y|a}_i$.
La formule de porte avant donne alors Éq.~\eqref{eq:interference_id}.

\subsection{Ajustement par Variables Instrumentales (VI)}

\begin{definition}[Variable instrumentale]
Une variable $Z$ est un \emph{instrument valide} pour l'effet causal de $A$ sur $Y$ dans $\mathcal{G}$ si :
\begin{enumerate}[label=(\roman*)]
  \item \textbf{Pertinence :} $Z$ est corrélé avec $A$ (il existe un chemin causal $Z \to \cdots \to A$),
  \item \textbf{Exclusion :} $Z$ n'affecte $Y$ que via $A$ (tout chemin de $Z$ vers $Y$ passe par $A$),
  \item \textbf{Indépendance :} $Z$ est indépendant de tous les confondants non observés entre $A$ et $Y$.
\end{enumerate}
\end{definition}

\paragraph{Formule d'ajustement par VI (cas continu linéaire).}
Dans le cadre linéaire avec un seul instrument $Z$, l'estimateur de Wald identifie l'ATE :
\begin{equation}
  \text{ATE} = \frac{\mathrm{Cov}(Z, Y)}{\mathrm{Cov}(Z, A)} = \frac{\E{Y \g Z=1} - \E{Y \g Z=0}}{\E{A \g Z=1} - \E{A \g Z=0}}.
  \label{eq:iv_wald}
\end{equation}
Plus généralement, dans le cadre non-paramétrique, l'effet causal est identifiable via la formule générale :
\begin{equation}
  \pr(Y \g \rmdo(A=a)) = \sum_{z} \frac{\pr(Y, A=a \g Z=z)\, \pr(Z=z)}{\pr(A=a \g Z=z)},
  \label{eq:iv_general}
\end{equation}
qui découle de l'application du do-calculus (Règle 2) dans le graphe où $Z$ est d-séparé des confondants.

\paragraph{Intuition.}
L'instrument $Z$ crée une variation \emph{exogène} de $A$ : la partie de $A$ induite par $Z$ est non confondante, car $Z$ est indépendant des variables cachées.
En se concentrant sur cette variation exogène, on isole l'effet causal de $A$ sur $Y$ indépendamment du confondant.
C'est le principe fondamental de la régression à deux étapes (2SLS).

\paragraph{Exemple classique.}
$Z$ = distance à l'école la plus proche, $A$ = années de scolarité, $Y$ = salaire, $U$ = capacité innée (non observable).
La distance est un instrument valide si elle affecte la scolarité (pertinence) mais n'affecte le salaire que via la scolarité (exclusion) et est indépendante de la capacité innée (indépendance).

\paragraph{Lien avec le motif \textsc{Instrument} (HCM).}
Dans le modèle HCM collapsé/marginalisé, $Q^{a|z}_i$ joue le rôle de l'instrument : il est corrélé avec le traitement $A$, non confondant avec $Y$ conditionnellement à $U_i$, et son effet sur $Y$ passe entièrement par le traitement.
La formule de repondération Éq.~\eqref{eq:instrument_id} est l'analogue non-paramétrique de l'estimateur de Wald dans ce contexte hiérarchique.

\paragraph{Limites des trois critères.}
\begin{itemize}
  \item \textbf{Porte arrière} : requiert que l'ensemble de confondants $\mathbf{Z}$ soit entièrement \emph{observé}. Inapplicable si des confondants restent cachés.
  \item \textbf{Porte avant} : requiert l'existence d'un médiateur \emph{observable} interceptant tout le chemin causal, et l'absence de chemin de porte arrière de $A$ vers ce médiateur.
  \item \textbf{Variables instrumentales} : requiert un instrument parfaitement exogène (indépendant de $U$). En pratique, cette hypothèse d'exclusion est souvent difficile à vérifier et peut être violée.
\end{itemize}
Ces limitations motivent précisément l'extension aux HCM : la structure hiérarchique fournit une source \emph{interne} d'identification (les données intra-unit) qui peut se substituer à des instruments extérieurs ou des confondants observés.

\subsection{Limitations avec les données hiérarchiques}

Les CGM standards modélisent $n$ unit échangeables indépendantes.
Lorsque les données ont une structure hiérarchique (sub unit $j$ au sein d'unit $i$), l'agrégation naïve (par ex., moyenner $Y_{ij}$ pour obtenir $\bar{Y}_i$) peut perdre les informations nécessaires à l'identification.
La variable confondante $U_i$ rend l'identification impossible à partir des moyennes d'unit $(\bar{A}_i, \bar{Y}_i)$, mais avec des données au niveau des sub unit $(A_{ij}, Y_{ij})$, l'identification devient possible.

\subsection{Modèles Causaux Structurels Hiérarchiques (HSCM)}

\begin{definition}[Modèle Causal Structurel Hiérarchique (HSCM)]
Un HSCM $\Mc$ étend un SCM classique à deux niveaux d'observation :
\begin{itemize}
  \item \textbf{Variables au niveau de l'unit} $\mathbf{S} = \{S_1, \ldots\}$ avec équations structurelles $S_k = f_k(\pa_\Sc(S_k), E_{S_k})$.
  \item \textbf{Variables au niveau de la sub unit} $\mathbf{L} = \{L_1, \ldots\}$ avec équations structurelles $L_k = f_k(\pa_\Sc(L_k), E_{L_k})$.
  \item Une plaque extérieure indexant les unit $i \in \{1,\ldots,n\}$ et une plaque intérieure en pointillé indexant les sub unit $j \in \{1,\ldots,m\}$.
  \item Bruits exogènes : au niveau de l'unit $\{E_{S_k,i}\}$ et au niveau de la sub unit $\{E_{L_k,ij}\}$, tous mutuellement indépendants.
\end{itemize}
\end{definition}

La caractéristique graphique clé est la \emph{plaque intérieure} : les variables à l'intérieur (au niveau sub unit) sont répliquées $m$ fois par unit, tandis que les variables extérieures (au niveau unit) apparaissent une fois par unit.

\subsection{Trois Motifs Canoniques HCM}

Tout au long de ce travail, trois structures HCM fondamentales apparaissent régulièrement :

\paragraph{\textsc{Confondant}.}
Units : $U_i$ (latent). Sub unit : $A_{ij}$ (traitement), $Y_{ij}$ (résultat).
Équations structurelles : $A_{ij} = f_A(U_i, E_{A,ij})$, $Y_{ij} = f_Y(A_{ij}, U_i, E_{Y,ij})$.
Avec seulement les moyennes d'unit, l'effet causal de $A$ sur $Y$ est non identifiable ; avec les données de sub unit, il est identifiable via régression par unit.

\paragraph{\textsc{Confondant \& Interférence}.}
Ajoute une variable observée au niveau de l'unit $Z_i$ qui agrège les traitements individuels : $Z_i = g(\{A_{ij}\}_j)$.
$Z_i$ affecte ensuite $Y_{ij}$ via un effet de débordement (interférence).
Le modèle collapsé a $Q^a_i \to Z_i \to Q^{y|a}_i$, permettant l'identification via un raisonnement de type porte avant.

\paragraph{\textsc{Instrument}.}
Le résultat $Y_i$ est au niveau de l'unit, tandis que l'instrument $Z_{ij}$ et le traitement $A_{ij}$ sont au niveau de la sub unit.
$Z_{ij}$ est un instrument exogène affectant $A_{ij}$, qui à son tour affecte $Y_i$.
L'identification utilise une stratégie de type VI dans le modèle collapsé.

\subsection{Variables Q et Modèles Graphiques Causaux Hiérarchiques}

Pour réaliser l'identification, le HSCM est d'abord converti en un \emph{Modèle Graphique Causal Hiérarchique} (HCGM) en rendant explicite le rôle de l'aléatoire au niveau de l'unit via les \textbf{variables Q}.

\begin{definition}[Variable Q]
Pour une variable au niveau sub unit $L$ avec parents au niveau sub unit $\mathrm{pa}_L(L) \subseteq \mathbf{L}$, la variable Q est :
\begin{equation}
  Q^{L \g \mathrm{pa}_L(L)}_i \;:=\; \pr\!\left(L \g \mathrm{pa}_L(L), \text{unit}=i\right),
\end{equation}
c'est-à-dire la distribution conditionnelle de $L$ étant donné ses parents sub unit, telle qu'induite par l'aléatoire au niveau de l'unit $U_i$.
\end{definition}

Intuitivement, les variables Q sont des distributions aléatoires au niveau de l'unit : $Q^{Y|A}_i$ représente ``comment l'unit $i$ mappe les traitements aux résultats'', capturant le mécanisme causal spécifique de l'unit.

\section{Pipeline d'Identification HCM}
\label{sec:pipeline}
%% ========================================================

\subsection{Vue d'ensemble}

Le pipeline d'identification HCM, tel qu'implémenté dans notre package, suit six étapes précises.
Chacune correspond à une fonction spécifique de notre code :

\begin{algorithm}[h!]
\caption{Pipeline d'identification HCM}
\label{alg:pipeline}
\begin{algorithmic}[1]
\Require HSCM $\Mc$ avec graphe $\mathcal{G}$, traitement $A$, résultat $Y$
\State \textbf{collapse}$(\Mc)$ : convertir $\mathcal{G}$ en $\mathcal{G}_\col$ en remplaçant les variables sub unit par leurs variables Q.
\State \textbf{suggest\_augment\_for\_outcome}$(\Mc, Y)$ : suggérer les variables Q à ajouter pour rendre $P(Y|\rmdo(\cdot))$ identifiable.
\State \textbf{augment\_collapsed\_model}$(\mathcal{G}_\col, \hat{q}, \text{parents})$ : augmenter une variable à la fois.
\State \textbf{marginalize\_augmented\_model}$(\mathcal{G}_\aug, \hat{q}, \text{parents spéciaux})$ : marginaliser si nécessaire.
\State \textbf{identify\_effect}$(\mathcal{G}_{\aug/\mar}, Y, X)$ : appliquer le do-calculus via pyAgrum.
\State \textbf{ast\_to\_estimator}$(\text{ast}, \text{données}, a_\star)$ : évaluer numériquement l'estimande identifié.
\end{algorithmic}
\end{algorithm}

\paragraph{Rôle central de l'AST (backend formel de la librairie).}
Le point clé de ce pipeline est la transition \emph{formel $\rightarrow$ numérique}. La fonction \texttt{identify\_effect} (pyAgrum) ne renvoie pas seulement une formule lisible (\texttt{formula\_latex}) : elle renvoie aussi une représentation arborescente de l'expression causale (\texttt{ast}). Cette AST encode explicitement les opérateurs (sommes, produits, intégrales, conditionnelles, interventions) et la structure exacte de la fonctionnelle identifiée.

Dans notre backend, cette AST est l'objet de référence pour les calculs formels : elle sert à vérifier la forme de l'estimand, à tracer les dépendances de facteurs, et surtout à construire l'évaluateur numérique via \texttt{ast\_to\_estimator}. Autrement dit, \texttt{formula\_latex} est la vue humaine, tandis que \texttt{ast} est la vue exécutable ; c'est ce couplage qui constitue le cœur de la librairie.

\subsection{Étape 1 : \texttt{collapse(hscm)}}

\begin{definition}[Collapse]
Le modèle collapsé $\mathcal{G}_\col$ est un CGM plat sur les variables au niveau de l'unit.
Les variables sub unit $L_{ij}$ sont remplacées par leurs variables Q $Q^{L|\text{pa}_L(L)}_i$, qui sont des objets au niveau de l'unit.
Formellement, c'est le CGM limite quand le nombre de sub unit $m \to \infty$ : dans cette limite, les distributions empiriques des variables sub unit convergent vers les variables Q, et le modèle résultant au niveau de l'unit est un CGM standard.
\end{definition}

La fonction \texttt{collapse} implémente l'Algorithme 1 de l'article : chaque variable sub unit $v$ est remplacée par $Q^v$ (si $v$ n'a pas de parents sub unit) ou $Q^{v|\text{pa}_S(v)}$ (sinon). Les arcs sont mis à jour selon :
\begin{itemize}
  \item parent unit $\to$ sub unit $v$ devient parent unit $\to Q^v$,
  \item sub unit $v \to$ unit $w$ devient $Q^v \to w$.
\end{itemize}

\begin{lstlisting}[caption={Utilisation de \texttt{collapse}}]
from hierarchicalcausalmodels.do_calculus import collapse

collapsed = collapse(hscm)
# collapsed est un CausalGraphicalModel plat avec des noeuds Q^a, U, etc.
\end{lstlisting}

\paragraph{Exemple : motif \textsc{Confondant}.}
Pour l'HSCM confondant :
\begin{center}
$U_i \to A_{ij} \leftarrow U_i,\quad U_i \to Y_{ij} \leftarrow A_{ij}$
\end{center}
le collapse donne : $Q^a_i \leftarrow U_i \rightarrow Q^{y|a}_i$. Les deux variables Q sont confondues par $U_i$.

\subsection{Étape 2 : \texttt{suggest\_augment\_for\_outcome}}

Avant d'augmenter, il faut savoir \emph{quelles} variables Q ajouter.
La fonction \texttt{suggest\_augment\_for\_outcome} implémente la stratégie de l'article : pour rendre $E[Y|\rmdo(\cdot)]$ identifiable, on ajoute un nœud $\hat{Q}^y$ représentant la distribution marginale de $Y$ au sein de l'unit.

\begin{lstlisting}[caption={Suggestion des variables d'augmentation}]
from hierarchicalcausalmodels.do_calculus import suggest_augment_for_outcome

q_hat, q_hat_parents = suggest_augment_for_outcome(hscm, outcome_subunit='Y')
# q_hat = "Q^y"
# q_hat_parents = {"Q^a", "Q^{y|a}"}  (ancetres sub unit de Y)
\end{lstlisting}

La logique suit l'équation (4140) de l'article : la marginalisation $Q^y$ est une fonction déterministe des conditionnelles $Q^{v|\text{pa}_S(v)}$ pour tout $v$ ancêtre sub unit de $Y$.
Les parents de $\hat{Q}^y$ sont donc $\{Q^{v|\text{pa}_S(v)} : v \in \text{an}_S(Y)\}$.

\subsection{Étape 3 : \texttt{augment\_collapsed\_model} (variable par variable)}

\begin{definition}[Augmentation]
Le modèle augmenté $\mathcal{G}_\aug$ est construit à partir de $\mathcal{G}_\col$ en ajoutant un nœud auxiliaire $Q^Y_i$ (la distribution marginale du résultat dans l'unit $i$).
Ses parents sont toutes les variables Q qui ont un chemin causal vers $Y$.
Cette augmentation est nécessaire pour rendre certains chemins d'identification disponibles dans le CGM plat.
\end{definition}

L'augmentation se fait \emph{variable par variable} : pour chaque variable suggérée, on appelle séparément la fonction \texttt{augment\_collapsed\_\allowbreak model}.
Le nœud $\hat{q}$ est marqué observé si et seulement si tous ses parents Q sont observables (calculables à partir des données de sub unit).

\begin{lstlisting}[caption={Augmentation variable par variable}]
from hierarchicalcausalmodels.do_calculus import augment_collapsed_model

# q_hat_parents peut contenir plusieurs Q-variables
# On augmente une variable a la fois
augmented = augment_collapsed_model(collapsed, q_hat, q_hat_parents)
# augmented est le CGM collapsed + le noeud Q^y avec ses arcs
\end{lstlisting}

\paragraph{Exemple : motif \textsc{Confondant}.}
\begin{itemize}
  \item \textbf{Collapsé} : $Q^a_i \leftarrow U_i \rightarrow Q^{y|a}_i$.
  \item \textbf{Augmenté} : ajoute $Q^y_i$ avec parents $Q^a_i$ et $Q^{y|a}_i$.
\end{itemize}

\paragraph{Exemple : motif \textsc{Confondant \& Interférence}.}
\begin{itemize}
  \item \textbf{Collapsé} : $U_i \to Q^a_i \to Z_i,\; U_i \to Q^{y|a}_i \leftarrow Z_i$.
  \item \textbf{Augmenté} : ajoute $Q^y_i$ avec parents $Q^a_i$ et $Q^{y|a}_i$.
\end{itemize}

\subsection{Étape 5 : \texttt{marginalize\_augmented\_model}}

\begin{definition}[Marginalisation]
Dans certains graphes, le modèle augmenté viole la positivité (la distribution marginale $Q^Y_i$ peut avoir une densité nulle pour certaines valeurs).
Le modèle marginalisé $\mathcal{G}_\mar$ supprime de tels nœuds auxiliaires tout en préservant la validité de la formule d'identification.
\end{definition}

La fonction \texttt{marginalize\_augmented\_model} supprime le nœud $\hat{q}$ et reconnecte les arcs :
pour chaque variable dans $\hat{q}_{\text{parents spéciaux}}$, ses parents sont connectés directement au nœud $\hat{q}$ survivant.
Cette étape est optionnelle : si la positivité est satisfaite, le modèle augmenté est aussi le modèle marginalisé.

\begin{lstlisting}[caption={Marginalisation}]
from hierarchicalcausalmodels.do_calculus import marginalize_augmented_model

marginalized = marginalize_augmented_model(
    augmented_collapsed_model=augmented,
    q_hat=q_hat,
    q_hat_special_parents=q_hat_special_parents
)
\end{lstlisting}

\subsection{Étape 6 : \texttt{identify\_effect}}

\begin{definition}[Problème d'identification dans les HCM]
Étant donné un HCM, on souhaite identifier l'effet causal d'un traitement sub unit $A$ sur un résultat sub unit (ou unit) $Y$ sous une intervention douce $\rmdo(A \sim q^a_\star)$ :
\begin{equation}
  \pr\!\left(Y \g \rmdo(A \sim q^a_\star)\right) = \int \pr(Y \g \rmdo(A = a))\, q^a_\star(a) \, \di a.
  \label{eq:soft_intervention}
\end{equation}
L'intervention douce remplace la variable Q $Q^a_i$ par une distribution fixe $q^a_\star$, ce qui est une intervention plus naturelle dans les contextes hiérarchiques qu'une intervention dure (masse ponctuelle).
\end{definition}

La fonction \texttt{identify\_effect} est le point d'entrée unique pour le moteur de do-calculus.
Elle s'appuie sur pyAgrum pour construire un \texttt{CausalModel} à partir du CGM collapsé/augmenté/marginalisé et applique l'algorithme d'identification de Shpitser-Pearl.
Les listings complets de l'appel \texttt{identify\_effect} et de la structure \texttt{DoCalculusResult} sont fournis en annexe (\hyperref[app:implementation_details]{Détails d'implémentation}).

\begin{theorem}[Identification HCM via le modèle collapsé]
\label{thm:identification}
Soit $\Mc$ un HSCM avec modèle collapsé $\mathcal{G}_\col$ et modèle augmenté/marginalisé $\mathcal{G}_{\aug/\mar}$.
L'effet causal $\pr(Y \g \rmdo(A \sim q^a_\star))$ est identifiable à partir du HSCM si et seulement si l'effet correspondant sur les variables Q est identifiable dans $\mathcal{G}_{\aug/\mar}$ en utilisant le do-calculus.
\end{theorem}

\paragraph{Résultats d'identification pour les trois motifs.}

\paragraph{\textsc{Confondant}.}
Le do-calculus sur le modèle augmenté donne :
\begin{equation}
  \pr(Q^y \g \rmdo(Q^a = q^a_\star)) = \EE{Q^{y|a}}{\sum_a q^a_\star(a)\, Q^{y|a}(a)},
  \label{eq:confounder_id}
\end{equation}
ce qui se traduit par : faire la moyenne de la régression par unit $\hat{\mu}_i(a)$ évaluée en $a_\star$ sur toutes les unit.

\paragraph{\textsc{Confondant \& Interférence}.}
Identification de type porte avant :
\begin{equation}
  \pr(Q^y \g \rmdo(Q^a = q^a_\star)) = \sum_{z} \pr(Q^{y|a} \g Z=z)\, \pr(Z=z \g Q^a = q^a_\star).
  \label{eq:interference_id}
\end{equation}

\paragraph{\textsc{Instrument}.}
Formule de repondération de type VI :
\begin{equation}
  \pr(Y \g \rmdo(A \sim q^a_\star)) = \EE{Q^{a|z}, Q^z}{\frac{q^a_\star(a)}{Q^{a|z}(a \g z)} Y}.
  \label{eq:instrument_id}
\end{equation}

\subsection{Vue d'ensemble}

Étant donné une formule identifiée (par ex., Éq.~\eqref{eq:confounder_id}), il faut estimer les distributions conditionnelles requises à partir des données.
La structure des données est : $n$ unit, chacune contenant $m$ observations de sub unit $\{(a_{ij}, y_{ij})\}_{j=1}^m$.

\subsection{Étape 7 : \texttt{estimate\_causal\_effect} --- Estimation numérique de l'estimande}

La fonction \texttt{estimate\_causal\_effect} (dans \href{https://github.com/janisaiad/hierarchicalcausalmodels/blob/main/examples/new/estimation.py}{\texttt{examples/new/estimation.py}}) est le point d'entrée principal pour l'estimation numérique.
Elle prend le \texttt{DoCalculusResult} retourné par \texttt{identify\_effect} et évalue l'estimande numériquement à partir des données observées, en s'appuyant en interne sur \texttt{ast\_to\_estimator}.
Les paramètres détaillés utilisés dans les expériences sont externalisés \href{https://github.com/janisaiad/hierarchicalcausalmodels/blob/main/examples/STAR/params.md}{ici}.

\begin{lstlisting}[caption={Estimation numérique via \texttt{estimate\_causal\_effect}}]
from estimation import estimate_causal_effect

ate_estimate = estimate_causal_effect(
    result=result,              # DoCalculusResult d'identify_effect
    data={
        "A": A_matrix,          # shape (n_units, n_subunits)
        "Y": Y_matrix,          # shape (n_units, n_subunits)
    },
    intervention={"Q^a": 1.0},  # do(Q^a = 1.0)
)
print(f"ATE estime : {ate_estimate:.4f}")
\end{lstlisting}

\paragraph{Fonctionnement interne.}
La fonction délègue à \texttt{ast\_to\_estimator}, qui parcourt l'AST pyAgrum et construit un pipeline d'estimation composé :
\begin{itemize}
  \item Nœuds \texttt{Sum} $\to$ sommation Monte Carlo sur les unit.
  \item Nœuds \texttt{Integral} $\to$ intégration numérique.
  \item Nœuds \texttt{ConditionalDensity} $\to$ \texttt{ConditionalDensityEstimator} (paramétrique ou neuronal).
  \item Nœuds \texttt{Intervention} $\to$ remplace la distribution de la variable Q par $q^a_\star$.
\end{itemize}
Pour les variables Q (distributions aléatoires au niveau de l'unit), les matrices 2D brutes de sub unit sont automatiquement converties en paramètres par unit via \texttt{SubunitParamEstimator}.

\subsection{Estimation par unit (\texttt{ConditionalDensityEstimator})}

Pour chaque unit $i$, on estime la distribution conditionnelle $\pr(Y_{ij} \g A_{ij} = a, \text{unit}=i)$.
La classe \texttt{ConditionalDensityEstimator} supporte plus de 15 familles ; les paramètres détaillés sont documentés dans \href{https://github.com/janisaiad/hierarchicalcausalmodels/blob/main/examples/STAR/params.md}{\texttt{examples/STAR/params.md}}.

\begin{itemize}
  \item \textbf{Continue :} Gaussienne, Laplace.
  \item \textbf{Continue bornée :} Beta.
  \item \textbf{Continue positive :} Gamma, Log-normale, Exponentielle, Gaussienne inverse, Half-Cauchy.
  \item \textbf{Continue à queues lourdes :} Student-t.
  \item \textbf{Binaire :} Bernoulli.
  \item \textbf{Comptage :} Poisson.
  \item \textbf{Non-paramétrique :} KDE / k-NN.
\end{itemize}

\subsection{Estimateur ATE : cas \textsc{Confondant}}

Pour le motif \textsc{Confondant}, \texttt{estimate\_causal\_effect} évalue directement la formule identifiée.
L'estimateur résultant suit Éq.~\eqref{eq:confounder_id} :
\begin{equation}
  \widehat{\text{ATE}}(a_\star) = \frac{1}{n} \sum_{i=1}^n \hat{\mu}_i(a_\star),
  \label{eq:ate_estimator}
\end{equation}
où $\hat{\mu}_i(a_\star) = \int y \, \hat{Q}^{y|a}_i(y \g a_\star) \, \di y$ est la moyenne prédite du résultat pour l'unit $i$ au traitement $a_\star$.

Cet estimateur est cohérent quand $n \to \infty$ et $m \to \infty$ :
\begin{itemize}
  \item Pour $i$ fixé, $\hat{\mu}_i(a_\star) \to \E{Y_{ij} \g A_{ij}=a_\star, U_i=u_i}$ quand $m \to \infty$.
  \item La moyenne sur $i$ converge vers $\E{Y \g \rmdo(A=a_\star)}$ quand $n \to \infty$.
\end{itemize}

\subsection{Parallélisation des calculs d'ATE}

La parallélisation est un enjeu majeur pour la librairie : les évaluations de formules HCM (en particulier sur des graphes denses) peuvent devenir coûteuses dès que l'on multiplie les runs \texttt{do(1)}/\texttt{do(0)}, les variantes de graphes et les diagnostics.
Nous avons donc benchmarké trois modes d'exécution pour les calculs ATE sur les runs de référence 10--40 (source : \texttt{ate\_10\_40\_parallel\_speed\_test.json}, avec \texttt{HCM\_DISABLE\_MULTIPARENT\_Q\_PRECOMPUTE=1}).

\paragraph{Configuration.}

\begin{align*}
  U_i &\sim \mathcal{N}(0, 1) \\
  A_{ij} &= U_i + \varepsilon^A_{ij}, \quad \varepsilon^A_{ij} \sim \mathcal{N}(0, 0.5) \\

Le scénario 7 (29 régions $\times$ 35 segments $\times$ 7 semaines, 7\,105 obs.) confirme que l'estimateur par unit récupère $-7$~mph avec une erreur de 0{,}04, là où l'OLS naïf surestime le biais de congestion régionale de 40\,\%.
Le scénario 8 présente une forte variance d'échantillonnage ($n=8$ unit, $\mathrm{SD}\approx 81$--$108$~pts SAT) : l'erreur de 4{,}26~pts est attendue avec si peu d'unit ; l'apport essentiel est qualitatif — le signe est correct ($+4{,}49$) là où l'OLS naïf donne $-17$.
Le scénario 9 (NLSY79 synthétique, 50 régions $\times$ 60 individus) illustre le biais d'aptitude classique de Card (1995) : la prime salariale vraie de l'enseignement supérieur est 0{,}35 en log-salaire, l'estimateur par unit la récupère à 0{,}34 ($|\Delta|=0{,}01$), tandis que l'OLS naïf double l'effet ($+0{,}70$) en confondant le capital humain régional $U_i$ avec l'effet du diplôme.

\subsection{Présentation et motivation}

Le projet \emph{Tennessee Student/Teacher Achievement Ratio} (STAR) est l'une des expériences randomisées les plus célèbres en économie de l'éducation \citep{Krueger1999}. Environ 11\,600 élèves de 80 écoles du Tennessee ont été assignés aléatoirement, au sein de chaque école, à l'un de trois types de classes :
\begin{itemize}
  \item \textbf{Petite classe} : 13 à 17 élèves par enseignant,
  \item \textbf{Classe régulière} : 22 à 25 élèves,
  \item \textbf{Classe régulière avec aide} : 22 à 25 élèves avec un assistant.
\end{itemize}
L'expérience a couvert quatre niveaux scolaires (maternelle à CM1), avec des scores aux tests Stanford Achievement Test (SAT) et Tennessee Basic Skills First (BSF) comme mesures d'outcome.

Malgré la randomisation, les données STAR présentent une structure hiérarchique naturelle : les élèves sont imbriqués dans des classes, elles-mêmes imbriquées dans des écoles. Le traitement (type de classe) est assigné au niveau de la classe, non au niveau de l'élève. Appliquer directement une régression OLS avec effets fixes d'école -- comme dans l'approche canonique de \citet{Krueger1999} -- capture l'effet moyen mais ne modélise pas explicitement ce mécanisme hiérarchique. Les HCM permettent de formaliser précisément : (i) le niveau auquel le traitement opère, (ii) les confondeurs partagés au sein d'une classe, et (iii) la dérivation symbolique de la formule d'identification via le do-calculus.

\subsection{Pipeline d'analyse}

L'analyse procède en quatre étapes complémentaires.

\paragraph{1. Découverte causale plate.}
Nous appliquons PC, FCI, DirectLiNGAM et ExactBIC (\texttt{causal-learn}) sur un sous-ensemble de 4\,000 observations avec 7 variables (\texttt{readk}, \texttt{mathk}, \texttt{stark}, \texttt{gender}, \texttt{ethnicity}, \texttt{lunchk}, \texttt{schoolk}). Les graphes obtenus sont ensuite traduits en schémas HCM.

\paragraph{2. Explicabilité prédictive.}
Une forêt aléatoire est entraînée sur 5\,789 observations (114 variables one-hot). L'explicabilité est obtenue via SHAP, LIME et courbes PDP/ICE pour la variable de traitement \texttt{stark}.

\paragraph{3. HCM v1 et v2.}
Deux versions hiérarchiques sont construites : v1 (école $\to$ élève, 79 unit) comme preuve de concept, et v2 (classe/enseignant $\to$ élève, 322 unit) comme pipeline principal. Le do-calculus est appliqué sur le modèle collapsé augmenté via pyAgrum.

\paragraph{4. Référence économétrique.}
Nous répliquons la spécification de \citet{Krueger1999} : OLS et 2SLS sur 5\,725 observations de maternelle, avec effets fixes d'école et contrôles élève/enseignant.

\paragraph{Diagnostics graphiques utilisés dans le pipeline.}
En complément des estimations numériques, nous utilisons des diagnostics visuels pour vérifier la cohérence distributionnelle des variables et l'interprétabilité causale des graphes : distributions globales/queues lourdes, distributions de moyennes par classe, hétérogénéité de composition par classe, et graphes effectifs après neutralisation des facteurs manquants.

\paragraph{Formules d'identification (do-calculus, pyAgrum).}

Pour le graphe \textbf{DirectLiNGAM} (outcome $M$) :
\[
\tau_{\mathrm{DL}}(q^a_\star)
= \sum_{q^e,\, q^g,\, q^{l|e},\, q^{m|a,e,g,l},\, s}
  \pr(s \g q^e)\, \pr(q^{m|a,e,g,l})\, \pr(q^{l|e} \g s)
  \cdot \EE{}{Q^m \g Q^a{=}q^a_\star, Q^e, Q^g, Q^{l|e}, Q^{m|a,e,g,l}}\,
  \pr(q^g)\, \pr(q^e).
\]

Pour le graphe \textbf{ExactBIC} (outcome $M$) :
\[
\tau_{\mathrm{BIC}}(q^a_\star)
= \sum_{q^e,\, q^g,\, q^{m|e,y},\, q^{y|a,g},\, s}
  \pr(s \g q^e)\, \pr(q^{y|a,g} \g s)\, \pr(q^{m|e,y})
  \cdot \EE{}{Q^m \g Q^a{=}q^a_\star, Q^e, Q^g, Q^{m|e,y}, Q^{y|a,g}}\,
  \pr(q^g)\, \pr(q^e).
\]

\paragraph{Interprétation structurelle (PC, FCI, ConsensusMean).}
Pour PC, FCI et ConsensusMean, la formule identifiée se réduit à $P(Q^m)$ : l'intervention sur $Q^a$ disparaît de l'expression. L'estimande observée dans ces cas est donc principalement déterminée par la structure du graphe traduit, et ne doit pas être lue comme une conclusion empirique directe sur l'absence d'effet de la taille de classe.

\paragraph{Choix du graphe principal.}
Nous retenons \textbf{DirectLiNGAM} comme graphe narratif principal : c'est le seul graphe de découverte produisant un chemin explicite $A \to M$ dans la traduction HCM, ce qui rend l'estimande directement interprétable comme ``effet de la distribution de taille de classe sur le score de mathématiques''. Le graphe ExactBIC ($\mathrm{ATE} \approx 39{,}96$) illustre la sensibilité au choix de structure.

\subsection{Apport des HCM pour STAR}

Le cadre HCM apporte trois contributions méthodologiques précises par rapport aux approches standards sur STAR.

\paragraph{Niveau d'intervention correct.} L'OLS standard définit le traitement au niveau élève ($\mathrm{SMALL}_{ics} = 1$). Or, le type de classe est assigné au niveau classe. Le HCM intervient sur $Q^a$, la \emph{distribution} du traitement au sein de la classe, qui est la formulation naturelle pour une assignation de niveau classe.

\paragraph{Structure hiérarchique explicite.} Le graphe HCM v2 distingue les variables de niveau classe ($S$, $U$) des variables de niveau élève ($A$, $Y$, $M$, $G$, $E$, $L$). Cela permet de représenter le fait que l'urbanicité de l'école façonne le mécanisme traitement-outcome à un niveau différent des caractéristiques individuelles.

\paragraph{Identification symbolique via do-calculus.} Plutôt que de supposer un ensemble de backdoor à ajuster, le pipeline HCM applique le do-calculus sur le graphe collapsé augmenté et dérive symboliquement la formule d'identification. Les hypothèses d'identification sont ainsi explicites et vérifiables, ce qui renforce la transparence par rapport à l'OLS avec effets fixes.

\paragraph{Positionnement par rapport à l'état de l'art.} À notre connaissance, aucune implémentation existante ne combine découverte causale, identification HCM par do-calculus et estimation plug-in dans un pipeline unifié appliqué à des données hiérarchiques réelles. La bibliothèque \texttt{y0} (\texttt{y0-causal-inference}) a récemment introduit un support symbolique des HCM (janvier 2025) permettant de dériver des formules d'identification dans un DSL qui s'étend jusqu'au transport contrefactuel. Cependant, leur implémentation se limite à la dérivation symbolique et n'inclut pas d'estimation (ni ajustement de familles de distributions, ni évaluation numérique de la formule, ni calcul d'ATE à partir de données). Leur framework d'estimation \texttt{eliater} a été archivé peu avant leur PR HCM. Le présent travail constitue ainsi, à notre connaissance, le premier pipeline HCM de bout en bout, de la donnée brute à l'ATE estimé.

\subsection{Benchmark des familles de distributions}

\paragraph{Analyse distributionnelle des scores.}
Les scores de lecture (\texttt{gktreadss}) et de mathématiques (\texttt{gktmathss}) dans STAR sont des variables continues bornées, avec un support empirique approximativement dans $[300, 650]$. Un ajustement Gaussien, une loi log-normale et une loi de Student-$t$ ont été comparés par critère AIC sur l'échantillon complet ($n=5\,745$). La distribution intra-classe présente une asymétrie légère et des queues plus épaisses que la Gaussienne, ce qui motive l'utilisation de mélanges Gaussiens (GMM, $K=2$) ou de familles plus expressives.

\paragraph{Protocole de benchmark.}
Pour tester la sensibilité de l'ATE HCM au choix de famille de distributions pour les outcomes $Y$ et $M$, nous avons comparé quatre variantes sur un sous-échantillon de 28 classes (\href{https://github.com/janisaiad/hierarchicalcausalmodels/blob/psc/examples/STAR/star_variational_families_benchmark.py}{\texttt{star\_variational\_families\_benchmark.py}}, \href{https://github.com/janisaiad/hierarchicalcausalmodels/blob/psc/examples/STAR/star_baseline_and_hcm_benchmark.py}{\texttt{star\_baseline\_and\_hcm\_benchmark.py}}) :
\begin{itemize}
  \item \textbf{Gaussienne} (\texttt{gaussian}) : famille de base ; sous-estime les queues épaisses.
  \item \textbf{Bêta normalisée} (\texttt{beta}) : scores linéairement re-normalisés dans $(0,1)$, famille $\mathrm{Beta}(\alpha, \beta)$.
  \item \textbf{Gamma décalée} (\texttt{gamma}) : $Y - \min(Y) + \varepsilon$, adapte les scores à support positif.
  \item \textbf{Mélange Gaussien} (\texttt{gaussian\_mixture}, $K=2$) : famille choisie dans le pipeline principal ; capture les modes multiples potentiels dus à l'hétérogénéité enseignant.
\end{itemize}

\paragraph{Interprétation.}
Pour le graphe PC, la formule identifiée se réduit à $P(Q^y)$ indépendamment de la famille de distribution : l'effet interventionnel est donc de nature \emph{structurelle} pour ce graphe, quelle que soit la famille. La valeur de $E[\mathrm{do}(1)]$ change d'échelle selon la renormalisation (brut~: 430, bêta~: 5{,}1, mélange~: 0{,}6) sans modifier cette interprétation. Les graphes DirectLiNGAM et ExactBIC rencontrent une erreur de dimension (\texttt{X has 6 features, but LinearRegression is expecting 4}) dans ce benchmark antérieur à l'alignement régresseurs -- erreur corrigée dans le pipeline principal v2 (Tableau~\ref{tab:hcm_v2}). Le mélange Gaussien ($K=2$) reste la famille la plus expressive disponible et est retenu comme famille principale pour les outcomes continus dans le pipeline v2.

\paragraph{Note sur la structure à trois niveaux.}
STAR présente en réalité une structure à \emph{trois} niveaux : élèves $\subset$ classes $\subset$ écoles. Le cadre HCM tel qu'implémenté supporte deux niveaux (unit et sub unit). Deux stratégies d'agrégation sont possibles :
\begin{enumerate}
  \item \textbf{Agrégation élèves $\to$ classe (retenue)} : les classes deviennent les unit (niveau 1), les élèves les sub unit (niveau 2). L'école est une covariable de niveau unitaire ($S = \texttt{gksurban}$). C'est la stratégie v2 retenue, qui colle au mécanisme de randomisation (le traitement est assigné au niveau classe).
  \item \textbf{Agrégation classes $\to$ école} : les écoles deviennent les unit, les classes les sub unit. Cette formulation perd la variabilité intra-classe et ne capture pas directement le mécanisme de traitement.
\end{enumerate}
L'extension des HCM à des hiérarchies à trois niveaux (élève $\subset$ classe $\subset$ école) constitue une direction de recherche ouverte, qui permettrait de modéliser simultanément les effets de pairs au niveau classe et les effets d'établissement au niveau école.
En pratique, cette modélisation hiérarchique permet d'estimer plus finement l'effet causal propre de la taille de classe en corrigeant explicitement des biais de composition intra-classe, notamment l'hétérogénéité de genre, qu'il faut contrôler pour isoler l'effet de taille.

\section{Discussion}

\subsection{Enseignements clés}

\paragraph{Les données hiérarchiques comme ressource pour l'identification.}
Le message central du cadre HCM---et ce que nous avons validé expérimentalement---est que les données hiérarchiques peuvent transformer des problèmes non identifiables en problèmes identifiables.
La régression par unit conditionne implicitement sur la variable confondante latente au niveau de l'unit en traitant les données de sub unit de chaque unit comme un problème de régression séparé.

\paragraph{Le rôle des variables Q.}
Les variables Q sont le pont conceptuel entre le monde hiérarchique et le monde plat.
En rendant explicite l'aléatoire au niveau de l'unit comme des distributions aléatoires (plutôt que des variables aléatoires scalaires), le cadre HCM permet d'appliquer les outils standard des modèles graphiques causaux.
Le modèle collapsé est un CGM ordinaire, et les algorithmes d'identification existants fonctionnent sans modification.

\paragraph{Le do-calculus comme moteur d'identification.}
L'utilisation du do-calculus via pyAgrum permet une identification entièrement automatique : étant donné un nouveau HCM, le pipeline identifie, parse et estime sans codage manuel de l'estimateur.
La règle 2 du do-calculus (échange action/observation) est particulièrement centrale dans les HCM, car elle permet de remplacer les interventions sur les variables Q par des observations.

\subsection{Limitations et problèmes ouverts}

\paragraph{Hypothèse de $m$ grand.}
Les garanties théoriques reposent sur la limite $m$ grand (beaucoup de sub unit par unit).
En pratique, avec $m$ petit, les estimations par unit sont bruitées.

\paragraph{Hiérarchies multi-niveaux.}
Le cadre traite deux niveaux (unit, sub unit) mais de nombreux jeux de données réels ont un emboîtement plus profond.
Étendre les HCM aux hiérarchies à $K$ niveaux est un problème ouvert.

\paragraph{Positivité et chevauchement.}
L'identification requiert la positivité. En pratique, les violations de positivité peuvent conduire à une grande variance de l'estimateur.

\section{Conclusion}
\label{sec:conclusion}
%% ========================================================

Ce PSC nous a fourni une compréhension approfondie du cadre des Modèles Causaux Hiérarchiques de Weinstein et Blei (2023), ainsi qu'une expérience pratique d'implémentation et de validation expérimentale.

\paragraph{Théorie.}
Nous avons compris et redérivé les résultats théoriques clés : les transformations de graphes collapse/augment/marginalize, la réduction de l'identification HCM au do-calculus sur le modèle collapsé plat, et les trois stratégies d'identification (porte arrière, porte avant, VI) pour les trois motifs canoniques.

\paragraph{Implémentation.}
Nous avons construit un package Python complet articulé autour du pipeline :
\begin{enumerate}
  \item \texttt{collapse(hscm)} : transformation du HSCM en CGM plat.
  \item \texttt{suggest\_augment\_for\_outcome(hscm, Y)} : suggestion des variables Q à ajouter.
  \item \texttt{augment\_collapsed\_model(collapsed, q\_hat, parents)} : augmentation variable par variable.
  \item \texttt{marginalize\_augmented\_model(augmented, q\_hat, parents)} : marginalisation si nécessaire.
  \item \texttt{identify\_effect(cgm, Y, X)} : identification automatique via do-calculus pyAgrum.
  \item \texttt{estimate\_causal\_effect(result, data, intervention)} : estimation numérique à partir du \texttt{DoCalculusResult}.
\end{enumerate}

\paragraph{Expériences.}
Nous avons validé la récupération de l'ATE sur les trois motifs HCM, confirmé les 11 cas de test du do-calculus, et démontré la généralité du cadre sur 5 familles de distributions.

\paragraph{Travaux futurs.}
Les extensions prometteuses incluent : les hiérarchies multi-niveaux, l'estimation bayésienne hiérarchique (pour $m$ petit), l'analyse de sensibilité aux violations de positivité, et les applications à des jeux de données réels (éducation, biologie, sciences politiques).

import numpy as np
from hierarchicalcausalmodels.models.HSCMParametric import HSCMParametric
from hierarchicalcausalmodels.do_calculus import (
    collapse,
    suggest_augment_for_outcome,
    augment_collapsed_model,
    marginalize_augmented_model,
    identify_effect,
)
from estimation import estimate_causal_effect

# 1. Specifier le HSCM
hscm = HSCMParametric(...)

# 2. Generer les donnees
data = hscm.sample_data()

# 3. Collapse
collapsed = collapse(hscm)

# 4. Suggestion des variables d'augmentation
q_hat, q_hat_parents = suggest_augment_for_outcome(hscm, 'Y')

# 5. Augmentation (variable par variable)
augmented = augment_collapsed_model(collapsed, q_hat, q_hat_parents)

# 6. Suggestion de parents elligibles pour la marginalisation pour les variables d'augmentation
marginalize_candidates = marginalization_Qc_eligible_parents(
    augmented, q_hat
  )

# 7. Marginalisation (si necessaire)
marginalized = marginalize_augmented_model(
    augmented, q_hat, marginalize_candidates
)

result = identify_effect(
    cgm=marginalized,
    Y="Q^y",
    X="Q^a",
    unobserved={"U"}
)
print("Identifiable :", result.identifiable)
print("Formule :", result.formula_latex)

# 9. Estimation numerique
ate = estimate_causal_effect(
    result=result,
    data={"A": data["A"], "Y": data["Y"]},
    intervention={"Q^a": 1.0},
)
print(f"ATE estime : {ate:.4f}")
